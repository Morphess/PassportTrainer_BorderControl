Generation
----------
The versioned generator is tools/map/generate-world-map.sh.
It downloads and verifies the exact source files above and invokes:

npx --yes mapshaper@0.7.61 \
  ne_10m_admin_0_countries_ukr.shp \
  -clean \
  -simplify weighted 15% keep-shapes \
  -proj robin \
  -each 'svg_id="region-"+ADM0_A3' \
  -o format=svg id-field=svg_id width=10000 world-map.svg

Mapshaper 0.7.61 is an offline generation tool only. It is not a Maven or
runtime dependency and is not bundled with the application. Mapshaper source is
licensed under MPL-2.0: https://github.com/mbloch/mapshaper/blob/master/LICENSE
