# Passport Trainer

Passport Trainer — локальний JavaFX-застосунок для вивчення паспортних документів країн світу.

На поточному етапі проєкт містить мінімальний стартовий екран і базову Maven-конфігурацію. Оригінальна колекція зображень у каталозі `Зразки паспортних документів/` не змінюється та ще не імпортується застосунком.

## Вимоги

- Java Development Kit 25 або новіший;
- Linux із графічним середовищем для локальної розробки;
- цільова платформа майбутнього релізу — Windows 10/11 x86_64.

Глобальна інсталяція Maven не потрібна. Репозиторій містить Maven Wrapper,
який під час першого запуску завантажує зафіксовану версію Maven 3.9.11.
Для першого запуску потрібен доступ до Maven Central.

Maven Wrapper використовує активний JDK. Налаштуйте JDK 25 один раз на рівні
системи, IDE або постійної конфігурації shell; експортувати `JAVA_HOME` перед
кожною командою не потрібно. Наприклад, у Fedora системний JDK можна вибрати:

```bash
sudo alternatives --config java
sudo alternatives --config javac
```

Перевірка активного JDK і Maven:

```bash
java --version
./mvnw --version
```

Якщо Maven працює на Java нижче 25, build зупиниться на фазі `validate` з
повідомленням про потрібну та фактичну версії Java.

## Development запуск

Єдина стандартна команда запуску JavaFX application:

```bash
./mvnw compile exec:exec
```

## Tests

```bash
./mvnw clean test
```

## Build

```bash
./mvnw package
```

У Windows використовуйте відповідні команди через `mvnw.cmd`.

## Каталоги

- `src/main/java/ua/passporttrainer/` — Java-код;
- `src/main/resources/` — FXML, CSS, шрифти, іконки та карти;
- `src/test/java/` — автоматичні тести;
- `docs/` — документація та аудит бази;
- `data/` — майбутні структуровані дані й схема SQLite;
- `passports/` — майбутній підготовлений read-only каталог ресурсів;
- `scripts/` — допоміжні сценарії;
- `release/` — конфігурація та результати підготовки релізів;
- `Зразки паспортних документів/` — незмінене джерело паспортних зображень.
