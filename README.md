# Passport Trainer

Розроблено **Passport Trainer** — локальний JavaFX-застосунок, який допомагає вивчати паспортні документи країн світу.

У поточній версії (baseline) реалізовано read-only SQLite-каталог, перегляд 139 канонічних емітентів і 521 паспортного документа, перегляд деталей реальних вихідних зображень (source images), а також інтерактивну карту світу з резервним списком (fallback). Оригінальну колекцію в каталозі `Зразки паспортних документів/` збережено як незмінне read-only джерело.

## Вимоги

Для роботи з проєктом знадобляться:

* Java Development Kit (JDK) версії 25 або новішої;
* Linux із графічним середовищем (використовується для локальної розробки);
* Windows 10/11 x86_64 — цільова платформа, для якої готується майбутній реліз.

Встановлювати Maven глобально не потрібно. До репозиторію додано Maven Wrapper, який під час першого запуску самостійно завантажує зафіксовану версію Maven 3.9.11 (для цього знадобиться доступ до Maven Central).

Maven Wrapper використовує активний JDK. Рекомендується налаштувати JDK 25 один раз на рівні системи, IDE або постійної конфігурації shell, щоб не експортувати `JAVA_HOME` перед кожною командою. Наприклад, у Fedora системний JDK можна вибрати так:

```bash
sudo alternatives --config java
sudo alternatives --config javac
```

Щоб перевірити активні версії JDK та Maven, необхідно виконати:

```bash
java --version
./mvnw --version
```

Збірку налаштовано так, що якщо Maven працюватиме на Java нижче 25-ї версії, процес зупиниться на фазі `validate` і повідомить про потрібну та фактичну версії Java.

## Запуск у режимі розробки (Development)

Для запуску JavaFX-застосунку використовується єдина стандартна команда:

```bash
./mvnw compile exec:exec
```

## Тестування (Tests)

Запустити автоматичні тести можна командою:

```bash
./mvnw clean test
```

## Збірка (Build)

Для пакування проєкту потрібно виконати:

```bash
./mvnw package
```

Під час роботи у Windows використовуються ті самі команди із заміною `./mvnw` на `mvnw.cmd`.

## Структура каталогів

Проєкт організовано наступним чином:

* `src/main/java/ua/passporttrainer/` — основний Java-код;
* `src/main/resources/` — FXML-розмітка, стилі CSS, шрифти, іконки та карти;
* `src/test/java/` — автоматичні тести;
* `docs/` — документація проєкту та результати аудиту бази даних;
* `data/` — канонічний маніфест, метадані та згенерований read-only SQLite-каталог;
* `tools/map/` — інструменти для відтворюваної генерації ресурсів карти Natural Earth;
* `passports/` — зарезервований каталог для підготовлених read-only ресурсів;
* `scripts/` — допоміжні сценарії;
* `release/` — конфігурації та артефакти підготовки релізів;
* `Зразки паспортних документів/` — вихідне, незмінне джерело паспортних зображень.

Детальнішу інформацію наведено в документації:

* [Аудит джерельної бази](docs/database-analysis.md);
* [Архітектура застосунку](docs/architecture.md).
